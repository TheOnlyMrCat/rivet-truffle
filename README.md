# rivet

Rivet is a toy RISC-V emulator I'm making as an excuse to learn [Zig](https://ziglang.org).
It currently implements the RV64GC architecture (RV64IMAFDCZicsr_Zifencei),
as well as the "Zicntr" and "Zihpm" extensions.

The emulator is a simple, single-hart (single virtual core) interpreter implemented in Zig.
It communicates (over FFI) with a Rust runtime which provides MMIO devices, including a serial port,
real-time clock, virtual block devices and a virtual network interface.

Floating-point support comes from Fabrice Bellard's [SoftFP](https://bellard.org/softfp/) library,
used under the MIT licence and modified to support version 2.2 of the RISC-V F/D extension specification.
Virtual networking is done in userland, and is provided by [libslirp](https://gitlab.freedesktop.org/slirp/libslirp).

## Building and running

This project is built using Rust 1.91.1 and Zig 0.15.2. Older versions might work, but are not tested.
It also requires a recent version of `dtc` (Device Tree Compiler) at build-time.
A `nix develop` dev shell is provided with all the required dependencies (see [#nix-flake](#nix-flake) for details).

Rivet can be built with `cargo build`.
It has one mandatory positional parameter: an executable file to load and run.

```bash
cargo run -- <path/to/executable>
```

If the passed executable is an ELF file, rivet will load it into memory using the ELF program header.
If the passed executable is a binary file (i.e. not an ELF file), rivet will load it into memory
contiguously starting at `0x8000_000`.

Additional options are available to control the virtual block and network devices:

- `--blk <path/to/image.img>`: Use the provided raw image as the backing file for one virtual block device.
  As of now, only read/write mounts are supported. (Can be specified up to 4 times)
- `--forward-tcp <host_port[:guest_port]>`: Open TCP port `host_port` on the host and forward traffic from it
  to `guest_port` on the guest.
  For example, to forward port `2222` on the host to port `22` on the guest (e.g. for ssh): `--forward-tcp 2222:22`.
  If `guest_port` is omitted, the `host_port` will be forwarded to the same port on the guest.

### riscof

RISCOF is an architectural test framework that allows RISC-V targets to be tested against a standard
reference model.

Documentation for running these tests is available in the [riscof/](riscof) directory of this repository.

### dqib_riscv64-virt

Rivet is able to run Debian images as generated by the [Debian Quick Image Baker](https://people.debian.org/~gio/dqib/).

The following steps assume you have built [OpenSBI] with a U-Boot payload and that `$OPENSBI_UBOOT`
points to the output folder containing `fw_payload.elf`.
The `nix develop .#u-boot` shell provides this, but it can otherwise be made by installing
the `u-boot-qemu` package (Debian), and compiling OpenSBI with the
`PLATFORM=generic FW_PAYLOAD_PATH=/usr/lib/u-boot/qemu-riscv64_smode/uboot.elf` make flags.
(I haven't tested this though, sorry. Nix is a lot more convenient)

1. Download a [`riscv64-virt`] image, and extract it into this repo at `dqib_riscv64-virt/`.
2. Convert the QCow2 image into a raw image using `qemu-img`:

   ```bash
   qemu-img convert -f qcow2 -O raw dqib_riscv64-virt/image.qcow2 dqib_riscv64-virt/image.img
   ```
3. Run Rivet on the converted image:

   ```bash
   cargo run -- $OPENSBI_UBOOT/fw_payload.bin --blk dqib_riscv64-virt/image.img
   ```

[OpenSBI]: https://github.com/riscv-software-src/opensbi/
[`riscv64-virt`]: https://gitlab.com/api/v4/projects/giomasce%2Fdqib/jobs/artifacts/master/download?job=convert_riscv64-virt

## Nix flake

This repository provides a nix flake including a package, an app, and three development shells.

Rivet can be run with `nix run`:

```bash
nix flake run sourcehut:~theonlymrcat/rivet -- <path/to/executable>
```

### Development shells

The flake provides three devshells:

- `default`: Provides Rust, Zig, `dtc`, and all libraries needed to build rivet.
  Also provides `riscv64-unknown-elf-gcc` and `riscv64-unknown-elf-objdump`, to aid in testing and debugging.
- `riscof`: Provides everything in `default`, plus [`riscv_sim_rv{32,64}[fd]{,_rvfi}`](https://github.com/riscv/sail-riscv), the Sail-generated reference emulator.
  Also provides `rivet` as from the `default` package of this flake, and provides the latest [`riscv-arch-test`](https://github.com/riscv-non-isa/riscv-arch-test)s in the `$RISCV_ARCH_TEST` env variable.
- `u-boot`: Provides everything in `default`, plus a build of [OpenSBI](https://github.com/riscv-software-src/opensbi) compiled with a [U-Boot](https://source.denx.de/u-boot/u-boot/) payload.
  The U-Boot payload is provided in the `$UBOOT` env variable, and the OpenSBI firmware binaries are provided in the `$OPENSBI_UBOOT` env variable.
